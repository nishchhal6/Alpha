# Alpha - Frontend Developer Internship Assignment

This project is a frontend application built as a part of the internship assignment. It is a feature-rich, responsive web page that replicates the core functionality and design of a modern car detail page, inspired by the Spinny website.

**Live Deployed Link:** [https://alpha-umber.vercel.app/](https://alpha-umber.vercel.app/)

---

## 🚀 Features

This project successfully implements all the required features from the assignment:

*   **Component-Based Architecture:** Built with Next.js, leveraging reusable React components for a clean and maintainable codebase.
*   **Interactive Image Gallery:** A polished image carousel on the main page with clickable thumbnails to update the view.
*   **Full-Screen Gallery View:** On clicking the main image, a full-screen gallery opens up, providing an immersive viewing experience with vertical thumbnails and tab-based navigation (Exterior, Interior, etc.), just like the reference design.
*   **360-Degree View Simulation:** A "Click to view 360" button opens a modal, demonstrating the placeholder for a 360° interactive viewer.
*   **Dynamic Price Calculator:** A functional calculator with sliders for "Number of Invites" and "Duration of Event" to compute and display a value in real-time.
*   **Responsive Design:** The entire layout is responsive and provides a seamless experience on different screen sizes.
*   **State-Driven UI:** The application uses React's state management (`useState`) to toggle between the main page and the full-screen gallery view, providing a smooth, single-page application feel without extra page loads for the gallery.

## 🚦 Getting Started

To run this project locally, follow these steps:

### Prerequisites

Make sure you have Node.js and npm installed on your machine.

*   [Node.js](https://nodejs.org/) (v18.x or later recommended)
*   [npm](https://www.npmjs.com/) (comes with Node.js)

### Installation

1.  **Clone the repository:**
    ```
    git clone https://github.com/nishchhal6/Alpha.git
    ```

2.  **Navigate to the project directory:**
    ```
    cd Alpha
    ```

3.  **Install dependencies:**
    ```
    npm install
    ```
